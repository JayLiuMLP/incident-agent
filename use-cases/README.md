# Use Cases

This directory contains comprehensive use case implementations that demonstrate real-world applications of the incident-agent system.

## Available Use Cases

### 1. Agent Factory with Sub-agents
- **Path**: `agent-factory-with-subagents/`
- **Description**: Multi-agent system with specialized sub-agents
- **Key Features**: RAG capabilities, agent orchestration, tool integration
- **Technologies**: Pydantic AI, FastMCP, vector databases

### 2. MCP Server Implementation
- **Path**: `mcp-server/`
- **Description**: Model Context Protocol server for tool integration
- **Key Features**: Tool registration, context management, API endpoints
- **Technologies**: FastMCP, TypeScript, Node.js

### 3. Pydantic AI Integration
- **Path**: `pydantic-ai/`
- **Description**: Pure Pydantic AI agent implementations
- **Key Features**: Type-safe agents, structured outputs, multi-provider support
- **Technologies**: Pydantic AI, OpenAI, Anthropic

### 4. Template Generator
- **Path**: `template-generator/`
- **Description**: Automated template generation for new projects
- **Key Features**: Dynamic scaffolding, context engineering patterns
- **Technologies**: Python, Jinja2, Context Engineering

### 5. AI Coding Workflows Foundation
- **Path**: `ai-coding-workflows-foundation/`
- **Description**: Foundation patterns for AI-assisted development
- **Key Features**: Code analysis, validation workflows, automated refactoring
- **Technologies**: AST parsing, static analysis, AI integration
